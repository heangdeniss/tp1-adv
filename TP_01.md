# Part 1 — Basic Python Programming Concepts

## 1. Variable

A **variable** is a name used to store a value in a program.

Example:

```python
student_name = "HEANG Denis"
student_age = 22
score = 95
```

Here:

- `student_name` stores text.
- `student_age` stores an integer.
- `score` stores a number.

We can use these values later in the program.

```python
print(student_name)
print(score)
```

### Simple idea

```text
Variable → stores a value
```

---

## 2. Function

A **function** is a reusable block of code designed to perform a specific task.

Example:

```python
def calculate_sum(a, b):
    return a + b


result = calculate_sum(5, 3)
print(result)
```

Output:

```text
8
```

Instead of writing the same calculation many times, we can call the function whenever we need it.

### Simple idea

```text
Function → reusable code that performs a task
```

---

## 3. Class

A **class** is a template or blueprint used to create objects.

Example:

```python
class Student:
    pass
```

The class `Student` describes a type of object that we can create later.

Example:

```python
student1 = Student()
```

`student1` is an object created from the `Student` class.

### Simple idea

```text
Class → blueprint
Object → something created from the blueprint
```

---

## 4. Method

A **method** is a function that belongs to a class.

Example:

```python
class Student:
    def study(self):
        print("The student is studying.")


student1 = Student()
student1.study()
```

Output:

```text
The student is studying.
```

In this example, `study()` is a method because it is defined inside the `Student` class.

### Simple idea

```text
Method → function inside a class
```

---

## 5. Constant

A **constant** is a value that is intended to remain unchanged during the program.

Example:

```python
PI = 3.14159
MAX_SCORE = 100
```

Python does not strictly prevent us from changing these values.

However, programmers normally write constants using uppercase letters to show that they should not be modified.

### Simple idea

```text
Constant → value that should remain fixed
```

---

## 6. Module

A **module** is a Python file that contains reusable code.

For example:

```text
calculator.py
```

Inside `calculator.py`:

```python
def add(a, b):
    return a + b
```

We can use this function in another Python file:

```python
import calculator

print(calculator.add(5, 2))
```

### Simple idea

```text
Module → one Python file containing reusable code
```

---

## 7. Package

A **package** is a directory that groups related Python modules together.

Example:

```text
data_tools/
│
├── __init__.py
├── cleaning.py
├── analysis.py
└── visualization.py
```

In this example:

```text
data_tools
```

is the package.

The files:

```text
cleaning.py
analysis.py
visualization.py
```

are modules.

### Simple idea

```text
Package → collection of related modules
```

---

# 📌 Basic Concept Summary

| Concept | Meaning |
|---|---|
| Variable | Stores a value |
| Function | Performs a reusable task |
| Class | Blueprint used to create objects |
| Object | Instance created from a class |
| Method | Function defined inside a class |

| Module | A Python file containing reusable code |
| Package | A folder containing related modules |

# Part 2 — Clean Code and Programming Best Practices

Writing code that works is important.

However, good programming also means writing code that other people can understand, modify, test, and maintain.

---

## 1. Readability

**Readability** means making code easy to understand.

Poor example:

```python
a = 10
b = 3
c = a * b
```

Better example:

```python
price = 10
quantity = 3
total_price = price * quantity
```

Both examples produce the same result.

However, the second example clearly explains what each value represents.

### Remember

```text
Readable code → easy to understand
```

---

## 2. Maintainability

**Maintainability** means making code easy to change or improve later.

Instead of repeating the same calculation:

```python
total1 = 10 * 2
total2 = 20 * 3
total3 = 15 * 4
```

We can create a function:

```python
def calculate_total(price, quantity):
    return price * quantity


total1 = calculate_total(10, 2)
total2 = calculate_total(20, 3)
total3 = calculate_total(15, 4)
```

If the calculation changes later, we only need to modify the function.

### Remember

```text
Maintainable code → easy to update
```

---

## 3. Efficiency

**Efficiency** means solving a problem while using time and computer resources effectively.

Example:

```python
numbers = [10, 20, 30, 40]
```

Instead of:

```python
total = 0

for number in numbers:
    total = total + number
```

Python already provides:

```python
total = sum(numbers)
```

The second solution is shorter and easier to understand.

### Remember

```text
Efficiency → use an appropriate and simple solution
```

---

## 4. Reducing Errors

Good programs should also handle possible errors.

Example:

```python
try:
    age = int(input("Enter your age: "))
    print(age)

except ValueError:
    print("Please enter a number.")
```

If the user enters something such as:

```text
hello
```

the program does not immediately crash.

Instead, it displays a useful message.

### Remember

```text
Error handling → manage unexpected problems safely
```

---

# 📊 Why Best Practices Matter

| Principle | Meaning | Example |
|---|---|---|
| Readability | Easy to understand | Use meaningful variable names |
| Maintainability | Easy to update | Put repeated logic in functions |
| Efficiency | Use an appropriate solution | Use built-in functions |
| Error Handling | Manage problems safely | Use `try-except` |

# Part 3 — PEP 8 Coding Style

## What is PEP 8?

**PEP 8** is the official Python style guide.

It provides recommendations for writing Python code in a consistent and readable way.

The main purpose is:

```text
Clean Code
   ↓
Consistent Code
   ↓
Readable Code
   ↓
Easier Collaboration
```

---

## 1. Use Meaningful Names

Variable and function names should describe their purpose.

Avoid:

```python
x = 50
y = 4
z = x * y
```

Prefer:

```python
product_price = 50
quantity = 4
total_price = product_price * quantity
```

Good names reduce the need for unnecessary explanations.

---

## 2. Variables and Functions Use `snake_case`

Python variables normally use lowercase words separated by underscores.

Example:

```python
student_name = "Reaksa"
final_score = 90
```

Functions follow the same style.

```python
def calculate_average():
    pass
```

### Remember

```text
Variables → snake_case
Functions → snake_case
```

---

## 3. Classes Use `PascalCase`

Class names normally begin each word with a capital letter.

Example:

```python
class StudentProfile:
    pass
```

Another example:

```python
class DataProcessor:
    pass
```

### Remember

```text
Classes → PascalCase
```

---

## 4. Constants Use `UPPERCASE`

Constants are normally written using uppercase letters.

Example:

```python
PI = 3.14159
MAX_USERS = 100
DEFAULT_TIMEOUT = 30
```

### Remember

```text
Constants → UPPERCASE
```

---

## 5. Use Four Spaces for Indentation

Python uses indentation to define code blocks.

Not recommended:

```python
if score >= 50:
  print("Pass")
```

Recommended:

```python
if score >= 50:
    print("Pass")
```

PEP 8 recommends using:

```text
4 spaces
```

for each indentation level.

---

## 6. Add Spaces Around Operators

Avoid:

```python
total=price*quantity
```

Prefer:

```python
total = price * quantity
```

This makes expressions easier to read.

---

## 7. Add Spaces After Commas

Avoid:

```python
scores = [70,80,90,100]
```

Prefer:

```python
scores = [70, 80, 90, 100]
```

The same rule applies to function arguments.

Avoid:

```python
calculate_total(10,2)
```

Prefer:

```python
calculate_total(10, 2)
```

---

## 8. Keep Imports Organized

Imports are normally placed near the beginning of the Python file.

Example:

```python
import math
import numpy as np
import pandas as pd
```

This makes dependencies easy to identify.

---

## 9. Keep Lines Readable

Very long lines can be difficult to read.

Instead of:

```python
result = calculate_final_price(price, quantity, discount, tax, shipping_cost, service_fee)
```

We can write:

```python
result = calculate_final_price(
    price,
    quantity,
    discount,
    tax,
    shipping_cost,
    service_fee,
)
```

This is easier to read and modify.

---

## 10. Use Blank Lines

Blank lines help separate different parts of a program.

Example:

```python
def add(a, b):
    return a + b


def subtract(a, b):
    return a - b
```

Without blank lines, larger files become difficult to read.

---

## 11. Write Useful Comments

Comments should explain useful information.

Unnecessary comment:

```python
# Add two numbers
result = a + b
```

Better comment:

```python
# Calculate the student's final score after applying the bonus
final_score = score + bonus
```

Comments are especially useful when the reason behind the code is not immediately obvious.

### Remember

```text
Good comments explain why something is done.
```

---

# 🐞 Basic Debugging Process

When my program does not work, I should not immediately rewrite everything.

I can follow this process:

```text
Run the program
      ↓
Read the error
      ↓
Find the line causing the problem
      ↓
Understand the error type
      ↓
Check the values
      ↓
Fix one problem
      ↓
Run again
```

For example:

```python
student_age = "20"

print(student_age + 5)
```

This causes an error because `"20"` is a string while `5` is an integer.

A possible correction is:

```python
student_age = "20"

print(int(student_age) + 5)
```

Output:

```text
25
```
